# *Приложение типа e-commerce*

## Цель

_**Это второй учебный проект**_. <br>
Основная цель - закрепление полученных знаний в период обучения и получение практики написания кода на языке Python  

## Установка

* Скопировать репозиторий на ПК: <br>
`git clone https://github.com/Nekrontir/SkyPro_second_project.git` 
* В проекте используется Poetry, для установки виртуального окружения и всех зависимостей 
необходимо использовать команды: <br>
`poetry install`, `poetry sync`

## Содержание проекта

Проект содержит модули:
1. core_classes.py - содержит классы представления товара и категории  
2. utils.py - содержит вспомогательные функции для получения данных

## Тесты

Репозиторий содержит тесты. Используется фреймворк PyTest.
Для запуска тестов с автоматическим формированием результатов необходимо выполнить команду:
`pytest --cov=src --cov-report=html`
